# Логотип Школы Актива

В шапке сейчас стоит цветок из брендбука: `public/brand-sha/flower-black.png`. Он автоматически показывается на всех экранах. Отдельного файла-логотипа (круглые варианты «ШКОЛА АКТИВА 2026» / «ША 26» из брендбука) в репо пока нет — они есть только внутри `docs/brandbook/brandbook-strip.png`.

Когда дизайнеры отдадут логотип отдельным файлом:
- предпочтительно SVG с корректным `viewBox`, без внешних ресурсов и скриптов, шрифты в кривых;
- прозрачный фон; версия, читаемая на бумаге `#F5F1E6`;
- компактный знак ~квадратных пропорций (контейнер 56×56 desktop / 46×46 mobile, см. `.committee-logo` в `src/styles.css`);
- положить как `public/brand-sha/logo.png` (или `.svg`) и поменять `src` в `src/components/CommitteeBrand.tsx`;
- пересобрать: `npm run build`.

При ошибке загрузки показывается текстовая заглушка «ША». Фавикон — `public/favicon.svg`.
