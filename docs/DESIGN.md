# Школа Актива 2026 — визуальная система Mini App

Основа: брендбук ША 2026 (`docs/brandbook/`): мятая бумага, пиксельная типографика, 7 фирменных цветов, цветы с глазами и 3D-элементы (сердце, звезда, луна, молния, курсор).

Палитра (снято пипеткой с `colors.png`):
- зелёный `#2CE719` / светлый `#C5FFA8`
- фиолетовый `#BF2AFF` / светлый `#E9B6FF`
- оранжевый `#FF8512` / светлый `#FFDBAB`
- синий `#1C63FF` / светлый `#A6BFFF`
- жёлтый `#FFCC00` / светлый `#FFF2BC`
- чёрный `#252525`, красный `#F70302` / светлый `#FFA8A7`
- бумага `#F5F1E6`, чернила `#252525`

Шрифты: заголовки — пиксель (`Retrogression`, `KONKOVO 2026`, фолбэк monospace); акценты — `Cormorant 2026` (подключён с Google Fonts) и `Bickham Script One` (фолбэк cursive); текст — `SF Pro` (фолбэк system). Файлы `Retrogression`/`KONKOVO`/`Bickham` в репо нет — если появятся `.woff2`, положить в `public/brand-sha/fonts/` и добавить `@font-face` в `src/styles.css`.

Характер: цветы-маскоты вместо пингвина (`Mascot` показывает PNG из `public/brand-sha/`), чёрный CTA-блок как «Стекло», жёлтая полоса, оранжевая кнопка, зелёная кнопка в CTA, сиреневые бейджи. Обои ТГК ужаты в `wallpaper-hero.png` (900px) для финального экрана; оригиналы — в `docs/brandbook/` и в Docker-образ не попадают.

Движение: цветок покачивается и наклоняется за указателем; переходы между экранами короткие; `prefers-reduced-motion` отключает декорации.
